# Templates — gc.profile.doc-vault

Reusable templates for governed document repositories.

---

| file | purpose |
|---|---|
| `document-lifecycle-policy.template.md` | Formal document lifecycle and version governance policy for an entity |
| `version-index.template.md` | Version history table for a governed document folder |
| `document-index.template.md` | Master registry of all governed records in a repository |
| `legal-hold-notice.template.md` | Formal notice placing records under legal hold |
| `external-document-intake.template.md` | Intake record for received, issued, or confirmation documents |
| `chain-of-custody-log.template.md` | Log of material movements and actions on records |
| `redaction-log.template.md` | Log of redacted copies created from original records |

---

All templates use `[placeholder]` syntax for fields that must be customized per entity.  
Templates are not governed records and do not require version control unless formally adopted as policy.
