# Governance Commons v1.2.0

## Public release train

Governance Commons v1.2.0 is the first public release-train boundary for the frozen OSS core.

### Release boundary

The PASS-5 Batch 2 OSS baseline is frozen at this release boundary. The release is intentionally stable: new category-defining capabilities are not baseline requirements for v1.2.0 adopters.

### Included standards

- Agent Dossier — v1.1.0
- Agent Matrix — v1.4.0
- Ontic Namespace Structure (ONS) — v1.3.0
- Agent Project Orchestrator — v1.1.0

### Public adoption surfaces

- Governance Commons website: https://governancecommons.org
- Conformance profiles and badge criteria are published on the website.
- GitHub Releases provide the versioned specification artifacts and release notes.
- Python and JavaScript/TypeScript reference implementations are maintained in the Governance Commons Registry.

### Baseline freeze

PASS-6 is the next capability track. PASS-6 profiles are optional extensions to the frozen v1.2.0 baseline; they do not retroactively become v1.2.0 requirements.

The project uses scoped language such as “aligned with,” “informed by,” and “supports readiness for” where a Governance Commons artifact references an external framework. This release does not constitute certification or legal compliance.

### Release verification

The release manifest is `releases/gc-v1.2.0.yaml`. Each specification remains independently versioned, with the release manifest defining the public compatibility boundary.
